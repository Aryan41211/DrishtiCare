# Fovea Localization CNN — Implementation Plan

**Goal:** Build a patch-CNN + sliding-window locator that finds the fovea center in a fundus image, mirroring the existing MA-CNN / OD-CNN pattern.

**Architecture:** Positive/negative patch dataset built from IDRiD fovea GT CSV centers (positives jittered at GT, negatives away from both fovea and optic disc, inside retina). A small 4-conv-block CNN (16/32/64/128, BN+ReLU+maxpool+GAP+FC2) classifies 192px green-channel patches as `{'FOV','BG'}`. A sliding-window locator (row-major crops + explicit map build, exactly like `locateOpticDiscCnn`) finds the max-P(FOV) grid cell, with an acceptance gate.

**Tech Stack:** MATLAB R2026a, Deep Learning Toolbox, idagree `createRetinalMask` for retina foreground.

**Spec:** Task description in conversation (DrishtiCare fovea localization module).

### Task 1: `src/lesions/buildFoveaDataset.m`

Dataset builder mirroring `buildOdDataset.m`:
- Load fovea CSV (`C. Localization/2. Groundtruths/2. Fovea Center Location/IDRiD_Fovea_Center_Training Set_Markups.csv`), header `Image No,X- Coordinate,Y - Coordinate`. IDRiD_001 -> [1494 1970].
- Parse numbers from `IDRiD_###` column into numeric index; store full-res GT `gtCenters` (54x2).
- S=4, PH=192, HOLDOUT=1:10 (val), rest train.
- POSITIVES: P patches anchored at GT center with small jitter. Fovea radius `R = round(0.030*min(H,W))` @full-res, then at scale S use `R4 = round(R/S)`. Jitter ±0.25*R4.
- NEGATIVES: P patches centered away from BOTH fovea GT and optic disc, inside retina. Use `createRetinalMask(I)` for retina fg; build exclusion mask = retina AND far from fovea AND far from disc (disc center/radius from OD mask, exclusions at >=2.5*R_disc from disc center, >=2.5*R from fovea). Random sample from allowed region.
- OPTIC DISC mask dir: `A. Segmentation/2. All Segmentation Groundtruths/a. Training Set/5. Optic Disc/IDRiD_##_OD.tif`.
- Labels `{'FOV','BG'}` categorical; save `data/analysis/day8/fovea_cnn/fovea_dataset.mat` (patches, labels, imgIdx, split, HOLDOUT, PH, S, gtCenters).
- Print loaded GT center for IDRiD_001 (sanity, should be [1494 1970]) and per-image pos/neg counts.
